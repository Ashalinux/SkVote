# Minimalist, high-performance Votifier replacement for Skript users. Built for Minecraft 26.1.2.
## No Votifier or other dependencies needed ✔ (Generates public and private rsa keys!)




# Syntax is:
```
on online vote:
```

# Example:
```
on online vote:
    give player 10 diamond
    send "&aYou have voted for the server" to player
```
